## JithuBrowser 155.0.8059.39.1 (first pre-release, Linux x86_64)

A privacy-focused browser built on official Chromium **155.0.8059.39**. Chrome-only websites keep working; pages just can't watch what you do.

### Download (pick one)

| Your system | File |
|---|---|
| Debian, Ubuntu, Linux Mint, Pop!_OS | `jithubrowser_155.0.8059.39.1_amd64.deb` |
| Fedora, RHEL 9+, Rocky 9+, Alma 9+, openSUSE | `jithubrowser-155.0.8059.39-1.x86_64.rpm` |
| Arch, Manjaro, EndeavourOS | use `packaging/arch/PKGBUILD` (it downloads the tarball below) |
| Any other 64-bit Linux | `jithubrowser-155.0.8059.39.1-linux-x64.tar.xz` |

Step-by-step instructions for beginners are in the [README](https://github.com/Jitheswar/JithuBrowser#install-beginners-guide). Check your download against `SHA256SUMS`.

Needs a 64-bit Linux with glibc 2.31 or newer (Debian 11+, Ubuntu 20.04+, Fedora, Arch, RHEL 9+). Not for RHEL/Rocky/Alma 8 or older. **There is no Windows build in this release yet.**

### What it hides from websites
Tab switching and window minimising (Page Visibility), window focus, browser fullscreen and window geometry, `history.length`, `navigator.webdriver`, exact version/OS/device in the User-Agent and Client Hints (looks like stock Google Chrome), keyboard layout, typing-rhythm timestamps, and which browser shortcuts you press. Also closed during an audit: `screen.avail*`, `screen.isExtended`, mouse `screenX/Y`, Wake Lock and `navigator.vibrate()` hidden-tab tells.

Known limits (see `docs/DESIGN.md`): background-tab timer/animation throttling can still reveal a hidden tab; `performance.now()` inside a key handler is not jittered; auto-repeat of reserved shortcuts and the Find bar can still leak; the Navigation API shows true history depth.

### What was tested
- **Privacy suite, 19 tests, on this exact release binary: 19 pass.** The same suite on stock Chrome 155 fails 15 of the 19 (the other four cannot tell the difference in the Xvfb test environment).
- The `.tar.xz` and the contents of the `.deb` were unpacked and launched in a clean Ubuntu 22.04 root filesystem: `--version` and a page load work, the user agent is plain Chrome, and the profile is created in `~/.config/jithubrowser` (separate from Chromium's).
- The `.deb` metadata is valid and apt resolves its dependencies on Ubuntu 22.04; the `.rpm` contents, permissions and setuid sandbox were verified.

### Not tested yet
