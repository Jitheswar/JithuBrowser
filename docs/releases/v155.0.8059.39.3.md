## JithuBrowser 155.0.8059.39.3 (Linux x86_64 + Windows x64)

A privacy-focused browser built on official Chromium **155.0.8059.39**. Chrome-only websites keep working; pages just can't watch what you do.

### Important: replaces 155.0.8059.39.1 and .2
**The `.deb` files in those two releases could not be installed** (`dpkg` rejected them: "unsupported PAX tar header type"). That is fixed here and verified with a real install. The browser itself is unchanged; use this release.

### What it hides from websites
Tab switching and minimising, window focus, browser fullscreen and window geometry, `history.length`, `navigator.webdriver`, exact version/OS/device in the User-Agent and Client Hints (looks like stock Google Chrome), keyboard layout, typing-rhythm timestamps, which browser shortcuts you press, and hidden-tab tells in `screen.avail*`, `screen.isExtended`, mouse `screenX/Y`, Wake Lock and `navigator.vibrate()`. Every English menu, the About page and the installer text say "JithuBrowser".
Known limits are in `docs/DESIGN.md`: for example, background-tab timer throttling can still reveal a hidden tab.

### What was tested (and how)
- **Privacy suite, 19 tests.** Linux build: **19/19 pass** (stock Chrome 155: 15 fail). Windows build run under **Wine 11**: **19/19 pass** (stock Windows Chrome 155 under the same Wine: 14 fail). The few tests stock Chrome also passes cannot tell the difference in a virtual-display test setup.
- **Real installs.** `.deb`: installed with `apt`, run, and removed cleanly on Ubuntu 22.04 (sandbox helper setuid root, registered as the `x-www-browser` alternative). `.rpm`: installed with `dnf` on **Rocky Linux 9.8** with all dependencies resolved, ran and loaded pages, `rpm -V` clean, removed cleanly. `.tar.xz`: unpacked and launched.
- **Extensions.** Unpacked Manifest V3 extensions behave identically to stock Chrome: service workers start, content scripts run, `runtime` messaging / `chrome.storage` / `chrome.tabs` work, and a real Chrome Web Store extension (Dark Reader 4.9.133) restyles pages.
- **Real websites.** 20 sites (Google Search/Meet/Docs/Maps, YouTube, Wikipedia, GitHub, Reddit, Figma, Discord, Netflix, Spotify, Twitch, Amazon, Cloudflare, Zoom, ...): **18/20 load in both JithuBrowser and stock Chrome, 0 regressions, and no site showed an "unsupported browser" notice.** WhatsApp Web and Microsoft Teams loaded blank in both browsers on this network, so that says nothing about JithuBrowser.

### Not tested / be aware
- **Windows has not been run on real Windows**, only under Wine. It is cross-compiled on Linux, **not code-signed** (SmartScreen will warn: "More info", then "Run anyway"), WebGPU uses Windows' own shader compiler (the bundled DXC was not built), and it still shares some system registration IDs with Chromium, so do not install it next to Chromium on the same PC.
- A real `pacman`/Arch package build, and `.rpm` on Fedora/openSUSE (only Rocky 9 was tried).
- The setuid sandbox with real root was verified for file permissions only (tests ran in a rootless sandbox with `--no-sandbox`).
- Chrome Web Store *UI* installation (extensions were loaded unpacked), DRM/Widevine video, and the *functionality* of websites beyond loading and the "unsupported browser" check.
