## JithuBrowser 155.0.8059.39.8 (Linux x86_64 + Windows x64)

A privacy-focused browser built on official Chromium **155.0.8059.39**. Chrome-only websites keep working; pages just can't watch what you do.

### What's new in .8
- **Switching tabs no longer tells a fullscreen page.** On stock Chrome, leaving a tab that is fullscreen makes the browser exit fullscreen and fires `fullscreenchange` on the page, which reveals that you switched away. Now the window leaves fullscreen so the other tab is usable, but the page is told nothing; when you return to the tab, fullscreen is restored. Pressing Esc still exits and the page is told. Turn it off with `--disable-features=JithuBrowserSilentTabFullscreenExit`.
- Privacy suite grew to 28 tests (new: tab switch while fullscreen, silent fullscreen window usable, and more).

### What it hides from websites
Tab switching and minimising, window focus, browser fullscreen and window geometry, background-tab clocks and muted-video pausing (hidden tabs keep running like visible ones, at some extra CPU/battery cost; `--disable-features=JithuBrowserKeepHiddenTabsActive` turns it off), `history.length` and the Navigation API's history depth, `navigator.webdriver`, exact version/OS/device in the User-Agent and Client Hints, keyboard layout, typing rhythm (timestamps and `performance.now()`), which browser shortcuts you press, what you search for with Find in page, and hidden-tab tells in `screen.avail*`, `screen.isExtended`, mouse `screenX/Y`, Wake Lock and `navigator.vibrate()`. Own profile folder and enterprise-policy location, separate from Chromium's. Remaining limits are in `docs/DESIGN.md`.

### What was tested (and how)
- **Privacy suite, 28 tests.** Linux: **28/28 pass** (stock Chrome 155: 24 fail). Windows build under **Wine 11**: **28/28 pass** (stock Windows Chrome: 23 fail).
- **Sandbox**, default user-namespace sandbox as a normal user without `--no-sandbox`: renderers run with seccomp and `NoNewPrivs` (checked in .6; code unchanged in .8).
- **Chrome Web Store** "Add to Chrome" click installs an extension; **Widevine** DRM plays an encrypted stream end to end (both checked in .6).
- **Real installs** (previous releases' packages; packaging code is unchanged): Ubuntu 22.04 `.deb`; Fedora 44, Rocky 9.8, openSUSE Tumbleweed `.rpm`; Arch `makepkg` + `pacman -U`.
- **Real websites:** 20 sites, 18 load identically to stock Chrome, 0 regressions. **Extensions** behave identically to stock Chrome.

### Not tested / be aware
- **Windows has not been run on real Windows**, only under Wine. It is cross-compiled on Linux, **not code-signed** (SmartScreen will warn: "More info", then "Run anyway"), WebGPU uses Windows' own shader compiler, and it shares some system registration IDs with Chromium: do not install it next to Chromium on the same PC.
- The setuid sandbox helper with real root, and playback from a paid streaming service.
