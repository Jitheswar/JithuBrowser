## JithuBrowser 155.0.8059.39.2 (Linux x86_64 + Windows x64 installer)

A privacy-focused browser built on official Chromium **155.0.8059.39**. Chrome-only websites keep working; pages just can't watch what you do. This release replaces 155.0.8059.39.1.

### What's new since .1
- **Fully rebranded UI:** every English menu, the About page, settings, security warnings and installer text now says "JithuBrowser" instead of "Chromium" (156+891 strings; other languages fall back to English for the changed messages).
- **Windows installer** (new, **untested**, see below).
- Packaging fixes: correct file permissions in the `.deb`/`.rpm`, the `.rpm` keeps its setuid sandbox, glibc dependency corrected to 2.31.

### What it hides from websites
Tab switching and minimising, window focus, browser fullscreen and window geometry, `history.length`, `navigator.webdriver`, exact version/OS/device in the User-Agent and Client Hints (looks like stock Google Chrome), keyboard layout, typing-rhythm timestamps, which browser shortcuts you press, and hidden-tab tells in `screen.avail*`, `screen.isExtended`, mouse `screenX/Y`, Wake Lock and `navigator.vibrate()`.
Known limits are listed in `docs/DESIGN.md`: for example, background-tab timer throttling can still reveal a hidden tab.

### What was tested
- **Linux:** the 19-test privacy suite passes on this exact build (stock Chrome 155 fails 15 of the 19; the other 4 cannot tell the difference in the virtual-display test setup). The `.tar.xz` and the contents of the `.deb` launch in a clean Ubuntu 22.04 root filesystem, load pages, report a plain Chrome user agent and use their own profile folder (`~/.config/jithubrowser`). The `.deb` resolves its dependencies with apt on Ubuntu 22.04.
- **English UI:** the built English language pack contains 0 "Chromium" strings.

### Windows installer: please read
It was **cross-compiled on Linux** with Microsoft's public Visual Studio 2026 / Windows SDK 10.0.28000 toolchain. It is a valid 64-bit Windows installer containing a successfully linked `chrome.exe`, but **it has never been run on Windows**, and none of the privacy tests ran against it. Expect rough edges and please [report them](https://github.com/Jitheswar/JithuBrowser/issues).
- It is **not code-signed**, so Windows SmartScreen will warn ("More info", then "Run anyway").
- WebGPU uses Windows' own shader compiler (the bundled DXC was not built); `d3dcompiler_47.dll` comes from Windows itself.
- Do not install it next to Chromium on the same Windows PC: they still share some system registration IDs.
